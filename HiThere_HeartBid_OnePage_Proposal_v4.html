01. 기획 배경과 목표

기존 태그 게시글 → 하트/쪽지 → 1:1 채팅의 전환을 강화
문제

첫 메시지 진입 장벽

프로필과 게시글을 보고도 무엇을 보내야 할지 몰라 채팅을 시작하지 않는 상황을 줄임.

해결

질문에 먼저 답변

질문을 매개로 대화의 첫 소재를 만들고, 익명 답변을 선택하는 재미를 제공.

차별점

프로필보다 답변

외모·인기 중심 노출 대신 답변의 매력에 집중. 선택 이후에도 양측 동의 필수.

목표

실제 대화 연결

참여율보다 매칭 후 첫 대화율과 7일 재방문율을 핵심 성공 지표로 측정.

02. 제공된 HiThere 화면과 연계

첨부된 3개 실제 화면 기반 · 신규 기능 위치는 제안 사항

① 홈 피드

상단 로고·태그 탐색·게시글 카드 구조 유지. 태그 아래 하트경매 진입 배너를 추가하고 기존 게시글과 자연스럽게 병행.

② 태그 검색·목록

태그별 게시글 목록에서 관련 질문 이벤트를 노출. 선택한 태그에 따라 질문을 필터링하되 기존 검색·카드 동작 유지.

③ 캘린더

기존 월간 캘린더에 경매 마감일·결과 발표일을 표시하는 확장안. 별도 일정 데이터와 충돌하지 않도록 선택형 노출.

03. 핵심 사용자 시나리오

24시간 답변 모집 + 24시간 체험 채팅 · 시간과 횟수는 운영 제안값
STEP 01

질문 개설

질문 작성, 관심 태그 선택, 응답 기한 설정. 예: “나와 주말을 보낸다면?”

STEP 02

익명 답변 접수

다른 사용자는 질문에 답변. 작성자에게 닉네임·프로필은 우선 숨김.

STEP 03

마음에 든 답변 선택

마감 후 질문자가 1개 답변을 선택. 참가자에게 결과 알림.

STEP 04

상호 동의

선택된 응답자에게 연결 제안. 수락 시에만 프로필 공개 및 24시간 체험 채팅 시작.

STEP 05

1:1 채팅 시작

기존 채팅 UI를 활용한 임시 대화방으로 이동. 24시간 후 양쪽이 계속하기를 선택하면 일반 1:1 채팅으로 전환.

05. 픽업 이후 · 체험 채팅과 재선택

일방적인 거절 부담을 줄이는 2단계 매칭

하트경매에서 픽업은 최종 매칭이 아닙니다. 답변을 보고 선택한 뒤 실제로 대화해 보고, 양쪽이 모두 동의할 때만 일반 채팅으로 연결됩니다. 마음이 바뀌면 이유를 밝히지 않고 종료할 수 있습니다.

기존 1:1 채팅방으로 전환하고 대화 이력을 유지합니다. 서로의 최종 동의 후 정식 매칭 알림을 발송합니다.

한쪽 거절 또는 미응답

체험 채팅 종료. 상대에게는 “체험 채팅이 종료되었습니다”만 표시하고, 누가 거절했는지는 알리지 않습니다.

채팅 중 즉시 종료

메뉴에서 언제든 종료 가능. 신고·차단은 별도로 제공하며, 괴롭힘 상황에서는 제한 없이 즉시 이탈할 수 있습니다.

다른 답변자 재선택

원래 이벤트에 남아 있는 유효 답변 중 1명을 다시 선택할 수 있습니다. 운영안은 재선택 최대 1회, 동시 체험 채팅은 1건으로 제한합니다.

🛡️ 운영·보호 정책
  • 재선택은 기존 답변자 중 미선택·유효 사용자만 대상이며, 상대에게 ‘차선책’이라는 문구를 노출하지 않습니다.
  • 체험 채팅 종료 시 채팅방은 쓰기 불가 처리. 대화 기록 보관·삭제 기간은 개인정보 정책에 맞춰 별도 결정합니다.
  • 신고·차단 시 즉시 종료하고 재매칭 후보에서 상호 제외합니다.
  • 프로필 공개 범위는 사전 고지하며, 상대 수락 이후에도 개인정보·연락처는 자동 공개하지 않습니다.
  • 시간(24시간), 재선택 횟수(1회)는 출시 전 실험으로 조정 가능한 정책값입니다.

06. 핵심 정책 · 예외 처리

실서비스 출시 전 운영·법무·개인정보 검토 필요
항목제안 정책예외·보호 장치
참여 조건성인 사용자 대상 우선 검토, 계정당 동시 개설 1건 / 이벤트당 답변 1건차단 관계·신고 제한 계정은 상호 노출 제외
이벤트 기간개설 후 24시간 접수 → 질문자 픽업 → 상대 수락 → 24시간 체험 채팅 → 쌍방 최종 동의미선택·미수락 시 자동 종료, 최종 동의 전 정식 채팅 생성 금지
프로필 공개답변 제출 시 익명, 선택 후 상대가 수락하면 양측 프로필 공개연락처·위치·실명 노출 금지, 원치 않으면 언제든 거절
선택 정책동시에 1명만 체험 채팅, 선택 전 확인 팝업체험 채팅 종료 후 남은 유효 답변 중 최대 1회 재선택 가능(제안값)
신고·안전질문·답변 신고, 금칙어/스팸 탐지, 사용자 차단괴롭힘·성적 콘텐츠·개인정보 요구 대응, 반복 위반 계정 제한
보상·비용금전·코인 입찰 없음, 무료 참여‘경매’는 콘셉트 명칭이며 금전적 거래·확률형 보상 없음
알림답변 도착 요약, 마감 임박, 선택·수락 요청, 매칭 완료푸시 수신 동의 및 빈도 제한; 미수락 상대에 대한 반복 독촉 금지
기획 참고: 화면 ① 홈의 태그/피드/하트/쪽지, ② 태그 검색과 게시글, ③ 캘린더 구조는 첨부 이미지에서 확인한 요소입니다. 하트경매 배너, 익명 답변, 선택·수락, 일정 표시, 시간 제한, 참여 정책 등은 신규 제안이며 기존 HiThere에 이미 구현되어 있다는 의미가 아닙니다. ‘경매’는 재미를 위한 명칭으로 실제 금전 입찰은 포함하지 않습니다.
